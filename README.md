# 图片批量压缩器 · PXL Batch

[打开在线工具](https://niu866.github.io/batch-image-compressor/)

用浏览器本地处理图片。选择或拖入 JPG、PNG、WebP，设置输出格式、质量和最长边，点击「开始处理」。结果支持按张下载，也可打包为一个 ZIP。界面显示原图与输出的体积变化。

- 最长边填 0 保留原尺寸。缩放保持宽高比，仅缩小图像。
- PNG 支持透明，忽略质量设置。JPEG 的透明区域填白。动画图片输出静态帧。
- 每批最多 50 张，单张输入最多 30 MB、4000 万像素。ZIP 输出合计最多 160 MB。
- 浏览器将图像重新编码为选定格式。输出不携带源文件的 EXIF 等附加元数据。

本地开发可运行 python -m http.server 8080。ZIP 依赖 fflate，许可见 vendor 目录。
